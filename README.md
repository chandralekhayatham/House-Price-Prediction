# House-Price-Prediction
Machine Learning project to detect fraudulent transactions using SMOTE and Random Forest
# 💳 Credit Card Fraud Detection System

## 📌 Overview

This project detects fraudulent transactions using machine learning.

## 🚀 Features

* Handles imbalanced data using SMOTE
* Uses Random Forest and Logistic Regression
* Evaluates using precision, recall, F1-score
* Visualizes results using graphs

## 🛠️ Tech Stack

Python, Pandas, Scikit-learn, Imbalanced-learn, Matplotlib, Seaborn

## 📊 Results

* Improved fraud detection performance
* Better recall using SMOTE

## 📷 Outputs

* Confusion matrix
* Class distribution graphs

## 🎯 Conclusion

Machine learning helps detect fraud effectively in banking systems.
